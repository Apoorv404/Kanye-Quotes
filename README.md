# Kanye Quotes Generator

A desktop application that displays random Kanye West quotes with a simple, interactive GUI interface.

## Description

This application fetches random Kanye West quotes from the [kanye.rest](https://kanye.rest) API and displays them in a stylish window. Built with Python and Tkinter, it features a custom background and an interactive Kanye button that generates new quotes on demand.

## Features

- Clean and simple graphical user interface
- Random quote generation with a single click
- Custom styled display window
- Real-time API integration
- Custom Kanye West button image

## Requirements

- Python 3.x
- `tkinter` (usually comes with Python)
- `requests` library

To install the required packages:
```bash
pip install requests
```

## Usage

1. Clone or download this repository
2. Make sure all image files (`background.png` and `kanye.png`) are in the same directory as `main.py`
3. Run the application:
```bash
python main.py
```
4. Click on Kanye's image to generate a new quote

## Files

- `main.py` - The main application script
- `background.png` - Background image for the quote display
- `kanye.png` - Interactive Kanye button image
